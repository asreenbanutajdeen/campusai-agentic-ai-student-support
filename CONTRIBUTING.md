# Contributing

This repository is primarily an academic/internship demonstration project.

## Development guidelines

1. Keep the project simple and reproducible.
2. Do not commit secrets, API keys, credentials, or private institutional documents.
3. Keep demonstration data clearly labelled as demonstration data.
4. Update the README when changing setup steps or architecture.
5. Add or update tests when introducing non-trivial logic.

## Pull requests

Describe:
- What changed
- Why it changed
- How it was tested
- Any limitations or follow-up work
